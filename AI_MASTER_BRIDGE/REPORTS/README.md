# Raporty Work Bridge

Jeden plik na jedno zadanie: `WB-<ID>.md`.

Każdy raport musi zawierać:
- Task ID i status: DONE / PARTIAL / BLOCKED / FAILED;
- datę i środowisko;
- base branch + base commit SHA;
- branch wynikowy + head commit SHA (jeśli powstał);
- zmienione pliki i krótki opis diffu;
- dokładne polecenia testów/builda, kody wyjścia i czas;
- liczbę testów passed/failed/skipped albo NOT VERIFIED;
- wynik skanowania sekretów (bez wypisywania znalezionych wartości);
- ograniczenia, ryzyka i następny krok.

Nigdy nie zapisuj sekretów, pełnych zmiennych środowiskowych, tokenów, haseł, zawartości plików lokalnych ani danych osobowych.
