# Test czatu 0.1.6

1. Otwórz projekt w Android Studio i poczekaj na synchronizację Gradle.
2. Zbuduj przez **Build → Make Project**.
3. Uruchom aplikację i sprawdź, czy pole wpisywania pozostaje na dole, a historia przewija się niezależnie.
4. Wyślij długą wiadomość; sprawdź wielowierszowe wpisywanie i przewijanie historii.
5. Otwórz **＋ Załącz** i sprawdź wybór dokumentu oraz obrazu. Faktyczna analiza obrazu wymaga modelu obsługującego multimodalność.
6. Otwórz **☰ Rozmowy**, utwórz kilka czatów, przypnij jeden i sprawdź sekcje „Przypięte” oraz „Ostatnie”.
7. Podczas odpowiedzi sprawdź wskaźnik „AI myśli” i komunikaty etapów agentów.

Nie usuwaj poprzedniej działającej wersji, dopóki nie sprawdzisz nowego APK na telefonie.
