# Archiwum historycznych statusów buildów

Pliki w tym katalogu zachowują historyczne raporty wersji `BUILD_STATUS_*.md`.
Nie są źródłem bieżącego statusu kompilacji i nie wolno na ich podstawie deklarować
aktualnego PASS/FAIL projektu.

Jedynym bieżącym źródłem statusu jest plik główny `/BUILD_STATUS.md`.
